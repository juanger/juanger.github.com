I've been very busy this months and I haven't prepared the screencast, but here is a little present, the new version of Lucecita:

<a href="https://www.flickr.com/photos/juanger/2976552527/" title="Lucecita.app 2.0 by Juanger, on Flickr"><img src="/images/2008-10-26_lucecita-20/Lucecita-2.0.png" width="221" height="334" alt="Lucecita.app 2.0" /></a>

All the source code is hosted in github at <a href="https://github.com/juanger/lucecita">https://github.com/juanger/lucecita</a> and the DMG is here: <a href="https://raw.githubusercontent.com/juanger/lucecita/master/Lucecita.dmg">Lucecita.dmg</a>

It's a universal binary and only works in Leopard.[^2026-universal]

[^2026-universal]: The DMG still downloads from GitHub, but "universal" meant PowerPC plus 32-bit Intel back then (the binary is `ppc` and `i386`). macOS dropped 32-bit apps in Catalina (2019) and Apple Silicon never ran PowerPC, so it won't open on any current Mac.

Enjoy it!!
