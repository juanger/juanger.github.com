# Ruby Xocolatl

[blog.juanger.com](https://blog.juanger.com) — a small static blog generated by a
Bun + TypeScript generator (about 600 lines, 3 runtime deps). Write a markdown
file, push to `source`, and GitHub Actions builds and deploys it.

## Commands

```sh
bun install          # once
bun run dev          # build + watch + serve on http://localhost:3000 (live reload)
bun run build        # one build into out/ and exit
bun test             # golden render tests + URL-inventory test
```

`bun run dev` is a single process: it builds into `out/`, watches `posts/`,
`public/` and `pages/`, and live-reloads the browser over SSE. Drafts are shown in
dev with a red banner. **Edits to `src/` need a manual restart** (Ctrl-C and rerun).

## Writing a post

Create `posts/<lang>/YYYY-MM-DD_slug.md`, where `<lang>` is `en` or `es`:

```
posts/en/2021-04-16_on-remote-schools.md   ->  /en/2021/04/on-remote-schools
posts/es/2021-04-16_on-remote-schools.md   ->  /es/2021/04/on-remote-schools
```

- **The URL year/month/slug come from the filename**, always — not from the date
  field. This keeps every existing URL stable.
- **Translations pair by identical filename** across `en/` and `es/`. When both
  exist they cross-link automatically and emit `hreflang`.
- English posts also get `/blog/YYYY/MM/slug` redirect stubs (the old Octopress
  URLs). Add other legacy URLs with the `aliases` field below.
- **The markdown source is served at the post URL + `.md`** (e.g.
  `/en/2021/04/on-remote-schools.md`), a byte-identical copy of the source file;
  the `/blog/…` alias gets one too. Drafts are never copied.

### Front matter (YAML)

```yaml
---
title: On remote schools           # required
date: 2021-04-16 20:00             # display date; URL date still comes from the filename
description: One-line summary       # og:description + feed summary; defaults to the 1st paragraph
draft: true                        # excluded from build; shown only in `bun run dev`
image: /images/…/cover.png         # og:image override; defaults to /images/blog-og-image.png
translation: other-slug            # override pairing (default: same filename across en/ & es/)
aliases:                           # extra legacy URLs -> redirect stub to this post
  - /blog/2012/06/old-url/
categories: [opinion, life]        # string or list; parsed but not rendered
---
```

The legacy keys `layout`, `comments`, `colors`, and the errata fields `updated`,
`status`, `errata`, `note` are accepted and ignored (nothing is rendered from them).

## Tufte authoring syntax

Plain markdown plus a few small extensions. Raw HTML still works as an escape hatch.

| You write | You get |
|-----------|---------|
| `text[^note]` + `[^note]: …` | A numbered **sidenote** with a working mobile tap-to-open toggle |
| `text^[inline note]` | Same, inline footnote |
| `text[^m:label]` + `[^m:label]: …` | An unnumbered **margin note** (⊕ toggle) |
| `![alt](/img.png "Caption")` (image alone in a paragraph) | A `<figure>` with the caption as a margin note |
| `:::fullwidth` … `:::` | A full-width `<figure>` |
| `:::pullquote` … `:::` | A `<blockquote class="fullwidth">` with top/bottom rules |
| `:::epigraph` … `:::` | A `<div class="epigraph">` wrapper |
| `^^In his later books^^` | `<span class="newthought">` (small caps) |
| ```` ```ruby ```` fenced code | `<pre><code class="language-ruby">` |

Markdown `#`/`##`/`###` headings get slug `id`s (matching the old engine), so old
`#anchor` deep links keep working.

## How deploys happen

Push to the `source` branch. `.github/workflows/pages.yml` runs `bun install
--frozen-lockfile`, `bun test`, `bun run build`, and publishes `out/` to GitHub
Pages. The custom domain (`public/CNAME` → `blog.juanger.com`) is also set in the
repo's Pages settings. The old `master` branch is left untouched as a rollback.

## Favicon & social image

The favicon (`public/favicon.svg`, `favicon.ico`, `favicon.png`), the
`apple-touch-icon.png` and the default OpenGraph image (`public/og.png`,
1200×630, used as `og:image`/`twitter:image` on **every** page) are generated
from the self-hosted ET Book font by a one-off script:

```sh
bun run tools/make-icons.ts    # regenerate, then commit the files in public/
```

The script (opentype.js → SVG glyph paths, `@resvg/resvg-js` → PNG) is **not**
part of `bun run build`; its deps are devDependencies. Re-run it only when the
mark (the "RX" letters), the wordmark or the font changes, then commit the
regenerated assets.

## Layout

```
posts/{en,es}/*.md     posts (filename = URL date + slug)
pages/*.md             standalone pages (about, acerca+de)
public/                copied verbatim (favicon, icons, og.png, images, fonts, css, CNAME, stylesheets)
src/                   the generator (content, markdown, html, templates, feeds, build, dev)
tools/                 one-off asset generators (make-icons.ts — favicon + og.png), not run by the build
scripts/               CI helpers (check-urls.ts — post-deploy URL smoke check)
test/                  golden render tests + URL inventory (urls.txt)
urls.txt               every URL that must keep resolving
```
