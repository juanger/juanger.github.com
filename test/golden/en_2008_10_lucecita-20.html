I've been very busy these months and I haven't prepared the screencast, but here is a little present, the new version of Lucecita:

All the source code is hosted in github at https://github.com/juanger/lucecita and the DMG is here: Lucecita.dmg

It's a universal binary and only works in Leopard.2026The DMG still downloads from GitHub, but "universal" meant PowerPC plus 32-bit Intel back then (the binary is ppc and i386). macOS dropped 32-bit apps in Catalina (2019) and Apple Silicon never ran PowerPC, so it won't open on any current Mac.

Enjoy it!!
